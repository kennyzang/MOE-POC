# MOE SERPS POC — 演示口播稿（v2）

**预计时长：** 约 55–60 分钟（不含问答）  
**演示日期：** 2026-06-11（周四）  
**受众：** 文莱教育部领导层、各校校长、IT 相关干系人  
**系统地址：** http://localhost:3000（PC 端）/ http://localhost:5173（Mobile H5）

---

## 演示前准备清单

- 演示当天早上执行 `cd backend && npm run db:reset`（将初始化 3,456 名学生及所有模块数据）
- 启动后端：`cd backend && npm run dev`（端口 4000）
- 启动 PC 前端：`cd pc && npm run dev`（端口 3000）
- 启动移动端：`cd mobile && npm run dev`（端口 5173）
- 打开两个浏览器窗口：窗口 A（PC 端 localhost:3000），窗口 B（Chrome 开发者工具移动端模拟，访问 localhost:5173）
- 提前在一个独立标签页以 `admin / admin123` 登录（留备后用）
- 窗口 A 以登录页作为演示起始页面

## 第一幕：家长提交申请——公开注册门户（5 分钟）

**【新开标签页 → 访问 /register，无需登录】**

> "这是我们面向公众的学生注册门户，完全无需登录——任何家长都可以在家通过手机或电脑访问。无需纸质材料，无需到校排队。
>
> 系统通过一个结构化的五步向导引导家长完成申请。"

**【逐步演示每个步骤】**

> "**第一步——学生个人信息。** 填写姓名、身份证号、出生日期、性别、国籍。注意当家长输入出生日期后，系统会自动计算年级——家长无需自行判断孩子属于哪个年级。
>
> **第二步——学业背景。** 填写此前就读学校、最近学业成绩，以及是否有特殊教育需求。这些信息帮助学校提前准备相应支持。
>
> **第三步——监护人信息。** 这里有个实用细节——电话号码字段带有国家区号选择器。默认为文莱 +673，同时支持马来西亚、新加坡、印度尼西亚、菲律宾、英国等国家区号——对国际生申请人非常实用。邮箱验证为即时内联校验。
>
> **第四步——支持文件。** 包括出生证明、学生身份证、家长身份证及护照照片。每份必传文件均有明确标注。家长直接在线上传文件——无需携带纸质原件到校。
>
> **第五步——确认并提交。** 家长可以在清晰的汇总页面核对所有填写内容。点击提交后，申请进入学校处理流程，并生成一个跟踪编号，家长可随时查询状态。"

## 演示者注意事项

1. **使用两个浏览器窗口** ——窗口 A 用于 PC 端，窗口 B 用于移动端（Chrome 开发者工具，iPhone 14 Pro 模拟）。如果屏幕空间允许，可并排放置。
2. **切换账号时不要着急。** 要旁白一句：*"现在我切换到家长视角——Siti 女士。"* 观众需要跟上你展示的是谁。
3. **故事线是叙事主轴。** 注册 → 教师日常 → 家长查看 → 管理层监督 → 风险检测 → KPI 仪表板。每一幕自然衔接下一幕。
4. **通知铃铛**是你最好的助手。在任何触发通知的操作之后查看它——请假审批、消息发送、缺席标记。这证明系统是"活的"。
5. **如果页面加载较慢**，用台词填补空白：*"系统正在从数据库查询实时数据……"*
6. **语言切换** ——在移动端演示（第六幕）期间展示一次。操作快速且令人印象深刻。
7. **Ahmad 是叙事主线** ——他出现在老师的班级里、家长的"我的孩子"视图里、学生门户里、辅导员的案例列表里，以及风险仪表板中。全程反复引用他。
8. **支付演示** ——第五幕中的信用卡支付环节是全场亮点。慢慢演示——展示卡号分段格式化、自动识别卡组织、支付处理动画和收据。
9. **已修复的细节** ——如果有人问到边缘情况（电话号码验证、文件上传等），这些都已经处理好了。自信演示即可。
10. **以指挥中心结尾** ——以校长 KPI 仪表板收尾，将全程所有演示串联在一起。他们看到的数字正是整个演示过程中每一个操作的最终体现。
