## 二、候选功能列表（按优先级排列）

### 🟢 P1 — 高价值、低风险、移动端天然适配

#### 1. AI 聊天助手（ChatBot）
- **来源**: PC 端已有 `ChatWidget`（SSE 流式响应 + 按角色预设问题）
- **实现路径**: 在移动端底部添加浮动聊天按钮，复用 `/api/v1/ai` 的 SSE 接口
- **移动端优势**: 语音输入（未来）、随时提问、家长快速获取子女信息
- **预估工时**: 4-6h（主要在 UI 适配，后端无需改动）
- **演示亮点**: "随时随地提问 AI 助手" — 与 PC 端形成多端 AI 体验

#### 2. 应用内通知列表
- **来源**: PC 端已有 `NotificationBell` + `notificationStore`（30s 轮询）
- **当前差距**: 移动端有 Web Push 但无应用内通知查看
- **实现路径**: 新增通知 Tab 或通知图标，调用 `/api/v1/notifications`，支持标记已读
- **预估工时**: 3-5h
- **演示亮点**: 家长收到缺席通知 → 点击跳转到考勤详情

#### 3. 公告查看（Announcements）
- **来源**: PC 端 SIS 模块 `/sis/announcements`，API: `/api/v1/announcements`
- **价值**: 家长/学生最常需要查看学校通知
- **实现路径**: 各角色首页增加公告卡片区域，点击可查看详情
- **预估工时**: 3-4h
- **演示亮点**: 学校发布紧急通知 → 移动端即时可见 + Push 提醒

#### 4. 家长消息中心（Messages）
- **来源**: PC 端家长门户 Messages 页面，API: `/api/v1/messages`
- **价值**: 家长-教师直接沟通，是家长日常高频需求
- **实现路径**: 家长 Tab 增加"消息"入口，展示对话列表 + 发送消息
- **预估工时**: 5-8h
- **演示亮点**: 家长收到教师私信 → 移动端回复 → 形成双向沟通闭环

---

### 🟡 P2 — 有价值，需适度开发

#### 5. 学生作业查看（Assignments）
- **来源**: PC 端学生门户 Assignments，API: `/api/v1/assignments`
- **价值**: 学生移动端查看作业/提交状态
- **实现路径**: 学生首页增加"作业"卡片，可查看列表和详情
- **预估工时**: 3-5h

#### 6. 学生成绩单（Report Card）
- **来源**: PC 端学生门户 Report Card，API: `/api/v1/grades`
- **当前差距**: 移动端成绩页已有 GPA + 成绩列表，但无成绩单视图
- **实现路径**: 成绩页增加"成绩单"入口，展示学期汇总成绩单视图
- **预估工时**: 3-4h

#### 7. 家长费用查看（Fees）
- **来源**: PC 端家长门户 Fees + SIS 费用模块，API: `/api/v1/finance`
- **价值**: 家长查看缴费状态、待缴费用
- **实现路径**: 家长首页/新 Tab 增加费用卡片
- **预估工时**: 3-5h

#### 8. 同意书签署（Consent Forms）
- **来源**: PC 端 SMS 同意书管理 + 家长门户，API: `/api/v1/communications`
- **价值**: 家长在手机上签署校外活动同意书，非常自然
- **实现路径**: 家长 Tab 增加"同意书"入口，查看 + 一键签署
- **预估工时**: 5-8h
- **演示亮点**: 学校发起活动 → Push 通知 → 家长手机签署 → 流程闭环

### 🔵 P3 — 锦上添花，可后续迭代

#### 9. 教师签到/签退
- **来源**: PC 端 `/attendance/staff-check-in`，API: `/api/v1/staff-attendance`
- **价值**: 教师到校时手机打卡
- **预估工时**: 4-6h

#### 10. 学生行为记录查看
- **来源**: PC 端 SIS Behavior + 家长门户 Behavior，API: `/api/v1/behavior`
- **价值**: 家长了解子女在校行为表现（奖惩记录）
- **预估工时**: 2-4h

#### 11. 校历查看
- **来源**: PC 端 SMS School Calendar，API: `/api/v1/sms` (events)
- **价值**: 学生/家长/教师查看学校日程
- **预估工时**: 3-4h

#### 12. 请假申请（教师端）
- **来源**: PC 端 EMS Leave Management，API: `/api/v1/leave`
- **价值**: 教师手机端提交请假
- **预估工时**: 6-10h
- **注意**: BACKLOG 中 P2 任务 SPEC-P2-A 即为此功能，PC 端也尚未完成 UI

#### 13. CCA 课外活动
- **来源**: PC 端 SMS CCA，API: `/api/v1/cca`
- **价值**: 学生查看/报名课外活动
- **预估工时**: 4-6h
