## 风险

| 风险 | 应对 |
|------|------|
| antd-mobile 组件不满足聊天 UI 需求 | 自定义 CSS 实现聊天气泡 |
| SSE 在 Mobile 环境兼容性问题 | 使用 EventSource API，备选 fetch + ReadableStream |
| 通知轮询影响移动端性能 | 页面隐藏时暂停轮询（Page Visibility API） |
| 时间不足 | Day 1 优先 AI 助手 + 通知列表，公告降级 |
