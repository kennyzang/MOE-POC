## Summary
Counselor Case Resolution — staff assignee picker, intervention workflow, and real file upload for session records.

## Time

## Completed Work

### Feature: Intervention Assignee — staff dropdown + notification
- `GET /counselor/staff` endpoint returns all active non-student/parent users (teachers, admins, etc.)
- "Assigned to" field in the intervention form changed from free-text `Input` to searchable `Select` showing all staff
- When an intervention is assigned, an in-app notification is sent to the selected person with a link to `/counselor/my-interventions`
- Schema: added `assignedToUserId String?` and `resultNotes String?` to `CounselorCaseActionItem`

### Feature: Assignee result workflow (loop back to counselor)
- New page `/counselor/my-interventions` — shows all interventions assigned to the current user
- Assignee can click "Start" (OPEN → IN_PROGRESS) or "Submit Result" to mark DONE with result notes
- When assignee marks DONE, counselor receives an in-app notification confirming completion
- Page accessible to teacher, hod, manager, finance, admissions roles (not just counselor)
- New PATCH `/counselor/interventions/:itemId` endpoint — only assignee or counselor/admin can update
- "My Interventions" added to Teacher Portal and Counselor Portal sidebars

### Feature: Real file upload in Session Record Documents
- Evidence form in `ResolutionDrawer` now supports actual file upload when `evidenceEntityId` is passed (the case ID)
- Uses existing `/files/upload` endpoint with `entityType='case_evidence'`
- After upload, filename auto-populated in form; file stored via `FileAttachment` model
- Uploaded files display as clickable download links (with download icon) in the evidence table
- Backward-compatible: existing metadata-only records still display as text
