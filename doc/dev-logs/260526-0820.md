## 关键决策

- **置信度公式**：最终使用 `min(60 + sessions×2.2, 95)`，Ahmad 10 次课 = 82%（与演示脚本一致）
- **Demo Fallback**：无 API Key 时自动切换预设答案 + 模拟流式输出（按词分块），演示不依赖真实 API
- **ChatWidget 全局注入**：在 AppLayout 注入，所有角色（student/parent/teacher/admin 等）登录后均可使用
