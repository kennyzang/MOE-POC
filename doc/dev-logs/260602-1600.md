## 详细记录

### 3A — 后端 `backend/src/routes/sen.ts`

| 端点 | 描述 |
|------|------|
| `GET /sen/students` | 列表，schoolId 过滤 + 诊断/级别过滤 + `_count` goal/session |
| `GET /sen/students/:id` | 完整 IEP：student info + goals + sessions（批量 userId→名称映射）|
| `POST /sen/students` | 注册，重复守卫（studentId uniqueness）|
| `PUT /sen/students/:id` | 更新诊断类型/级别/备注 |
| `DELETE /sen/students/:id` | 先删 sessions、goals，再删 SenStudent，不删 Student |
| `GET /sen/students/:id/goals` | 按 targetDate 排序 |
| `POST /sen/students/:id/goals` | 创建 goal |
| `PUT /sen/goals/:id` | 更新任意字段（inline status 变更走这里）|
| `DELETE /sen/goals/:id` | 删除 goal |
| `POST /sen/students/:id/sessions` | conductedBy 默认 req.user.userId |
| `DELETE /sen/sessions/:id` | 删除 session log |

**关键设计：**
- `enrichSessions()` helper 批量查 User 名称，避免 N+1
- 全部端点 requireRole(admin, manager, principal, hod, counselor)
- 沿用 Module 2 的 `req.params['x'] as string` 转型惯例

### 3B — 前端 `pc/src/pages/sen/SenStudentsPage.tsx`

**列表区**
- Filter：诊断类型（Select）+ 支持级别（Select）
- 表格：头像 + 姓名/学号 / 诊断 Tag / 级别 Tag / Goal 数徽标 / Session 数徽标 / 操作

**Register/Edit Modal**
- 注册模式：学生 debounced 搜索（≥2字符）+ 诊断 + 级别 + 备注
- 编辑模式：隐藏学生选择，仅显示诊断/级别/备注

**IEP Drawer（720px）**

Section 1 — 学生信息头：
- Avatar + 姓名/学号/班级 + 诊断/级别 Tag + 备注
- Edit 按钮关闭 Drawer 并打开编辑 Modal（避免嵌套状态冲突）

Section 2 — IEP 目标：
- 内联添加表单（非 Modal）：科目 + 日期 + 状态 + 描述
- 目标表格：科目 / 描述 / 目标日期 / **状态 inline Select**（onChange → 立即 PUT）
- 编辑 Modal（全字段）+ Popconfirm 删除

Section 3 — 支援记录：
- Ant Design Timeline，每条：日期 + 时长 + 执行人（resolved name）+ 内容
- Log Session Modal：日期 + 时长 InputNumber（addonAfter "min"）+ 执行人 + 备注
- 每条 Timeline 条目有 Trash2 Popconfirm 删除

**Sidebar**
- SIS 分组：加 `/sen/students`，角色 admin/manager/principal/hod/counselor（Brain 图标）
- Counselor Portal：同一路由再加一次，counselor 角色也能从自己的门户访问
