# MOE SERPS POC 开发日志

本目录记录每次 AI 对话的关键内容，作为项目开发日志存档。

## 日志格式

每次对话保存为一个 Markdown 文件，命名格式：`YYMMDD-HHmm.md`（对话开始时间）

每份日志包含：
- 对话时间（精确到分钟）
- Token 消耗估算
- 对话目标与产出
- 关键决策与变更
- 生成/修改的文件列表
