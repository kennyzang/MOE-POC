## 完成工作

### 后端

1. **emailService.ts** (`backend/src/services/emailService.ts`)
   - nodemailer + Office365 SMTP (smtp.office365.com:587, TLS)
   - 无收件人/无凭证时静默跳过

2. **notificationService.ts** (`backend/src/services/notificationService.ts`)
   - `send(userId, title, message, type)` — 同步写 DB，fire-and-forget 发邮件
   - `sendMany(userIds[], opts)` — 批量通知

3. **notifications.ts route** (`backend/src/routes/notifications.ts`)
   - `GET /api/v1/notifications` — 当前用户通知列表（最新50条）
   - `GET /api/v1/notifications/unread-count` — 未读数
   - `PATCH /api/v1/notifications/read-all` — 全部已读
   - `PATCH /api/v1/notifications/:id/read` — 单条已读

4. **6个事件触发点**
   - `attendance.ts` — 缺勤 → 通知学生 + 家长（type: warning）
   - `grades.ts` — 成绩录入 → 通知学生 + 家长（type: info）
   - `admissions.ts` — 录取状态变更 → 通知所有 manager（type: info）
   - `ems.ts` — 绩效评估提交 → 通知被评教师 + 所有 manager（type: info）
   - `sms.ts` — 设施预订 → 通知申请人（type: success）
   - `finance.ts` — 新增 `POST /api/v1/finance/invoices` + 通知学生 + 家长（type: warning）
