## 关键决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 数据库 | SQLite | POC 轻量，无需部署数据库服务 |
| 状态管理 | Zustand | 比 Redux 轻量，适合 POC 规模 |
| 认证 | JWT + localStorage | 简单有效，8h 过期 |
| 路由守卫 | 组件级 RoleRoute | 声明式配置，易于维护 |
| 菜单过滤 | useMemo + filterByRole | 递归过滤，角色配置集中管理 |
| 翻译结构 | 按模块分层 | common/auth/nav/roles/dashboard 分层 |

## 遇到的问题

1. **Playwright 工具加载**: 首次使用需要用户确认 Tool loaded
2. **Snapshot ref 过期**: 页面跳转后需要重新 snapshot 获取新 ref
3. **Write 前需 Read**: 编辑已有文件前必须先 Read
