## Technical Details

### AI Chat
- SSE streaming via `fetch()` + `ReadableStream` + `TextDecoder`
- `AbortController` for cancellation support
- `antd-mobile Popup` as bottom sheet (80vh, collapsible)
- Typing indicator with CSS bounce animation
- Role-based quick questions (student/parent/teacher)
- Conversation ID persistence for multi-turn chat

### Notifications
- 30-second polling for unread count via `setInterval`
- Optimistic updates for mark-as-read
- Type-colored icons (info=blue, warning=orange, success=green, error=red)
- Relative time display via `dayjs`
- Zustand store with cleanup function for polling

### Announcements
- Reuse `GET /api/v1/announcements` (role-filtered by backend)
- Max 3 items shown on each homepage
- Color-coded cards: urgent=red border/background, pinned=orange left border
- Detail page accessed via `/announcement/detail?id=xxx`
