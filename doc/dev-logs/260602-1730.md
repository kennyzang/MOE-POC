## 详细记录

### 4A — 后端 `backend/src/routes/library.ts`

| 端点 | 描述 |
|------|------|
| `GET /library/books` | 目录，schoolId 过滤 + search(title/author) + category + available |
| `GET /library/books/:id` | 详情 + activeLoans count + activeHolds count |
| `POST /library/books` | 添加书籍（admin/manager）|
| `PUT /library/books/:id` | 更新，totalCopies 变化时按比例调整 availableCopies |
| `DELETE /library/books/:id` | 有活跃借阅时返回 409 |
| `POST /library/books/:id/borrow` | 借阅：availableCopies 守卫 + 重复守卫，`$transaction` 原子操作 |
| `GET /library/loans` | 活跃借阅 + 动态计算 isOverdue/overdueDays/fineAmount（BND 0.10/天）|
| `GET /library/loans/:id` | 单笔借阅详情 |
| `POST /library/loans/:id/return` | 还书：存储 fineAmount，+1 availableCopies，首个 waiting hold → ready |
| `POST /library/books/:id/hold` | 只有 availableCopies = 0 时才允许预约 |
| `GET /library/holds` | 所有非取消预约，含 schoolId 过滤 |
| `PUT /library/holds/:id` | 更新状态（admin/manager only for "ready"）|
| `GET /library/fines` | 合并：已还 fineAmount>0 + 动态计算的活跃逾期，去重 |
| `POST /library/fines/:loanId/pay` | 清零 fineAmount + 写 AuditEvent（admin/manager/finance）|

**关键逻辑：**
- `computeOverdueDays()` helper：`Math.floor((end - dueDate) / 86400000)`
- 还书时自动升级首个 waiting hold 为 "ready"
- 借阅用 `prisma.$transaction([createLoan, decrementCopies])` 保证原子性

### 4B — 前端 `pc/src/pages/sms/LibraryPage.tsx`

**页头：** 图书馆图标 + SyncBadge（source: "KOHA", "5 min ago"）+ Add Book 按钮

**Catalogue Tab**
- 搜索 Input.Search（400ms debounce）+ 分类 Select + 仅显示可借 Switch
- 表格：书名 / 作者 / 分类 / 总册数 / 可借册数（绿/红 Badge）/ 操作
- 操作：可借 → Borrow 按钮；无库存 → Hold 按钮；Edit/Delete（admin）
- Delete 禁用时显示 Tooltip（有活跃借阅）

**Active Loans Tab**
- 逾期徽标 + "仅显示逾期" Switch

**Holds Tab**

- Mark Ready / Cancel 操作

**Fines Tab**

**Borrow/Hold Modal**：学生 debounced 搜索（≥2字符）+ 日期选择（borrow）
