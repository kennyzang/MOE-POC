## Bugs Fixed

### 1. Teaching Workload — No Data
**Root cause:** `schoolFilter(req)` returns `{ schoolId: smhk.id }` for school-scoped users, which was spread directly into the `TimetableSlot` Prisma `where` clause. But `TimetableSlot` has no `schoolId` field — Prisma threw a 500, frontend showed empty.

**Fix:** Filter via teacher relation instead:
```typescript
const sf = schoolFilter(req)
const teacherSchoolFilter = sf.schoolId ? { teacher: { schoolId: sf.schoolId } } : {}
where: { ...teacherSchoolFilter, ...semesterFilter }
```

### 2. Staff Attendance Dashboard — Counts Don't Sum to Total
**Root cause:** `absent` was counted from actual ABSENT records in DB. If daily-close hadn't run for today, staff with no record were uncounted, so `present + late + absent + onLeave < totalStaff`.

**Fix:** Derive absent from the total so the math always holds:
```typescript
const absent = totalTeachers - present - late - onLeaveCount
```
