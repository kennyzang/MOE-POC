## 完成内容

### 1. 招生文件下载（admissions document download）

**问题**：招生管理员能看到已上传文件列表，但无法下载/预览。

**改动**：
- `backend/src/routes/admissions.ts`：新增 `GET /admissions/documents/:docId/download` 端点，通过 `AdmissionDocument.filePath` 找到文件后 `res.sendFile()` 返回
- `pc/src/pages/sis/AdmissionsPage.tsx`：每条 `AdmissionDoc` 列表项增加下载按钮（`Download` 图标），调用 `downloadFile()` 工具函数；同时将文件列表移到上传框上方

### 2. 教师详情显示班主任班级

**问题**：Teacher Detail Page 看不出该教师是哪个班的班主任。

**改动**：
- `backend/src/routes/teachers.ts`：`GET /teachers/:id` 响应追加 `formClass` 字段（从 `ClassRoster.formTeacherId` 查询）
- `pc/src/pages/ems/TeacherDetailPage.tsx`：Overview Tab 的 Descriptions 中增加 "Form Class" 行；页面顶部标题区增加紫色 Tag 显示班级名

### 3. 修复学生考勤 Tab — 点名记录误放科目下

**问题**：Form Teacher 在 FormTeacherPage 提交每日点名时，Session 的 `courseId` 会绑定到某门课（DB schema 要求），导致学生详情页考勤 Tab 把点名记录归到"Science Year 7"等科目分组里。

**根本原因**：`AttendanceTab` 把所有记录按 `session.course.name` 分组，没有区分点名会话和上课会话。

**修复**（`pc/src/pages/sis/StudentDetailPage.tsx`）：
- 通过 `session.topic.startsWith('Daily Roll Call')` 识别点名记录
- 拆分为 `rollCallRecords`（点名）和 `subjectRecords`（科目）
- 先渲染独立的 **Daily Roll Call** 卡片（简化列：无"Session Topic"列，显示"X/Y days"），再渲染各科目分组
- 无需改动数据库结构或后端接口
