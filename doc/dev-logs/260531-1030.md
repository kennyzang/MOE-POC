## Bugs Found and Fixed

### Bug 1 — Present Rate > 100% (FIXED)
**Root cause:** Frontend formula `(totalRecords / sessions) × 100` computes records-per-session times 100, not a percentage.

**Fix:**
- Backend `GET /attendance/sessions`: added a `groupBy` query to return `presentCount` and `lateCount` per session (one extra efficient query)
- Frontend `AttendanceTrackingPage.tsx`: stats formula changed to `presentCount / totalRecords × 100`
- Color-coded: green ≥80%, orange ≥60%, red <60%
- **Result:** MATH701 shows 70.6% (was 107.7–116.7%)

### Bug 2 — Attendance Map Doesn't Save All Students (FIXED)
**Root cause:** The Mark Attendance modal defaulted radio buttons to "Present" visually but `attendanceMap` only recorded explicitly changed values. New sessions with no prior records would only save the students whose status was actively changed.

**Fix:** `useMemo` in `AttendanceTrackingPage.tsx` now initializes `attendanceMap` with all enrolled students set to `"present"` before loading existing records. Saved records override the default.

**Result:** After fix, saving 2 Present + 1 Absent → all 3 records written → Total 1→3 in session row.

### Bug 3 — Admissions Pipeline KPI Stale After Decision (FIXED)
**Root cause:** `decideMutation.onSuccess` only invalidated `['admissions']` query, not `['admissions-pipeline']`. The funnel and KPI cards use a separate query key.

**Fix:**
- Frontend: `decideMutation` and `updateMutation` now both call `queryClient.invalidateQueries({ queryKey: ['admissions-pipeline'] })`
- Backend: `POST /applications/:id/decide` now broadcasts `dashboard.applications.changed` SSE event so Command Center also refreshes

**Result:** After rejecting Farhan, pipeline funnel updated immediately: Submitted 12→11, Rejected 0→1.

### Bug 4 — Duplicate "Command Center" Sidebar Label (FIXED)
**Root cause:** Both `/dashboard` (strategic overview) and `/admin/command-center` (real-time KPIs) used the same label "Command Center" in the principal/admin sidebar.

**Fix:** Second item renamed to "Live KPI Center" via `defaultValue` update in `Sidebar.tsx`.

**Result:** Sidebar now shows distinct "Command Center" and "Live KPI Center" items.

### Bug 5 — File Preview URL Double-Prefix (FIXED, from earlier session)
**Root cause:** `downloadUrl` returned as `/api/v1/files/<id>/download`. When passed to `api.get()` which has `baseURL: '/api/v1'`, Axios strips leading `/` and concatenates → `/api/v1/api/v1/files/...` → 404.

**Fix:** Strip `/api/v1` prefix before passing to `api.get()` in `download.ts`, `FileList.tsx`, and `FileUploader.tsx`.

**Result:** Eye icon opens image modal correctly; Preview button after upload works.
