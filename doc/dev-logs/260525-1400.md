### 移动端项目（mobile/）— 全新建立

**技术栈**：Vite 5 + React 18 + TypeScript strict + antd-mobile 5.x + Zustand 4 + react-router-dom v6 + i18next + @tanstack/react-query + axios + lucide-react + dayjs

**核心基础设施**（6 个文件）：
- `src/types/index.ts` — 完整领域模型类型定义
- `src/lib/api.ts` — axios 实例，自动注入 Bearer token，401 自动跳转登录
- `src/lib/i18n.ts` — i18next 初始化，读取 localStorage 持久化语言
- `src/stores/authStore.ts` — Zustand persist，role 检查
- `src/stores/languageStore.ts` — 语言持久化
- `src/styles/global.css` — CSS 变量主题，移动端安全区适配

**多语言**（英/中/马来 三语）：
- `src/locales/en.ts` / `zh.ts` / `ms.ts` — 覆盖所有页面文本

**公共组件**（3 个）：
- `NavHeader.tsx` — 渐变蓝色顶部导航，支持返回按钮 + 退出登录图标
- `RoleTabBar.tsx` — 角色自适应底部 TabBar（家长3项 / 学生4项 / 教师3项）
- `AppLayout.tsx` — 组合 NavHeader + content + TabBar

**页面**（共 10 个）：

| 角色 | 页面 | 路由 | 数据来源 |
|------|------|------|---------|
| — | LoginPage | /login | POST /auth/login |

| 学生 | StudentHomePage | /student/home | GET /dashboard/stats |
| 学生 | StudentProfilePage | /student/profile | GET /students/me |
| 学生 | StudentCoursesPage | /student/courses | GET /students/me (enrollments) |
| 学生 | StudentGradesPage | /student/grades | GET /grades?studentId=... |
| 教师 | TeacherHomePage | /teacher/home | GET /dashboard/stats |
| 教师 | TeacherClassesPage | /teacher/classes | GET /teachers/me |
| 教师 | TeacherAttendancePage | /teacher/attendance | GET /attendance/sessions |

**路由**：`App.tsx` — BrowserRouter，RequireAuth 守卫，RoleRedirect 按角色跳首页
