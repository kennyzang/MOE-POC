## Work Completed

### 1. Fix: Roll Call edit shows saved data instead of defaults
- **Root cause:** `handleOpenRollCall` always initialized `rollCallMap` as empty `{}`, so all students defaulted to 'present' when editing
- **Fix:** Backend `GET /roll-call/today` now returns individual `records: [{studentId, status}]`. Frontend pre-fills `rollCallMap` from existing records when opening the modal. Removed confusing confirm dialog.
- **Files:** `backend/src/routes/attendance.ts`, `pc/src/pages/teacher/FormTeacherPage.tsx`

### 2. Fix: Teacher mobile tab bar missing Messages entry
- **Root cause:** `RoleTabBar.tsx` had no `/teacher/messages` tab, so teachers had no bottom-navigation way to access messages (only via notification links)
- **Fix:** Added Messages tab to teacher tab bar, replacing Announcements (announcements are still visible from teacher home page)
- **File:** `mobile/src/components/RoleTabBar.tsx`

### 3. Fix: Unify demo account passwords and lists
- **Root cause:** Demo accounts had various passwords (`teacher123`, `admin123`, etc.) making it confusing to switch accounts. Mobile had only 3 accounts vs PC's 22.
- **Fix:** All demo accounts now use `Demo@2026`. Moved `teacher01` to first position (default demo teacher). Added 5 more accounts to mobile login page. Updated seed data and start.sh.
- **Files:** `backend/prisma/seed.ts`, `pc/src/pages/auth/LoginPage.tsx`, `mobile/src/pages/auth/LoginPage.tsx`, `start.sh`

### 4. Fix: Registration documents not downloadable (filePath never set)
- **Root cause:** `beforeUpload` returned `false` so files never uploaded. Only filenames were stored.
- **Fix:** Frontend now reads files as base64 via FileReader; backend decodes and saves to `uploads/admission-docs/`, sets `filePath` on AdmissionDocument. Increased JSON body limit to 50mb.
- **Files:** `pc/src/pages/registration/RegistrationPortalPage.tsx`, `backend/src/routes/registration.ts`, `backend/src/index.ts`

### 5. Fix: Mobile parent messages page robustness
- Added `refetchOnMount: true`, `staleTime: 0` for always-fresh data
- Added error state with retry button
- **File:** `mobile/src/pages/parent/ParentMessagesPage.tsx`
