# 260527-1400 — AI & SMTP 配置增强 + Office365 认证排查

## 摘要（人工速览）

本次对话完成 AI 配置 UI 升级（对齐旧版功能）并向种子文件写入 SMTP/AI 默认值，
同时排查 Office365 SMTP 认证失败（535 5.7.3），确认为 Microsoft Basic Auth 禁用问题。

## 详细记录

### 问题背景
- 用户希望复用旧版 AI 配置（deepseek-chat / custom provider）
- 当前 AI 设置页面缺少 Base URL、Temperature、Max Tokens、System Prompt 字段
- .env 中 AI_API_KEY 未填写，导致测试连接报 "No API key configured"
- SMTP 测试报 535 5.7.3 Authentication unsuccessful

### 完成工作

#### 1. `.env` 更新
- AI 配置改为 custom/deepseek-chat/https://api.deepseek.com/v1，temperature=0.7，maxTokens=2048
- AI_API_KEY 写入（不入 git）
- SMTP 密码已在 .env（不入 git）

#### 2. `aiService.ts` — env fallback 补全
- `loadAiConfig()` 新增 `AI_ENABLED`、`AI_TEMPERATURE`、`AI_MAX_TOKENS`、`AI_SYSTEM_PROMPT` 的 env 变量 fallback
- 数据库值优先，env 次之，硬编码默认值兜底

#### 3. `SettingsPage.tsx` — AI Tab 重写
- Provider 改为 Select 下拉（anthropic / openai / custom 三选项）
- 新增 Base URL 字段（与 Model 并排两列）
- 新增 Temperature Slider（0-1，步长 0.1，实时显示数值）
- 新增 Max Tokens InputNumber（256-8192）
- 新增 Custom System Prompt 文本域
- Enable toggle 增加状态文字（Enabled — using real AI / Disabled — demo mode）
- 默认值对齐 .env（custom / deepseek-chat / https://api.deepseek.com/v1）

#### 4. `seed.ts` — SystemConfig 默认值
新增 SystemConfig upsert 块，重置数据库后自动写入：
- SMTP：smtp_host / smtp_port / smtp_user / smtp_from（不含密码）
- AI：ai_enabled / ai_provider / ai_model / ai_base_url / ai_temperature / ai_max_tokens（不含 api_key）

#### 5. `emailService.ts` — TLS 修复
- 删除 `tls: { ciphers: 'SSLv3' }`（已废弃）
- 改为 `tls: { minVersion: 'TLSv1.2' }`（Office365 要求）

#### 6. i18n（en / zh / ms）
新增字段：aiBaseUrl / aiBaseUrlPlaceholder / aiTemperature / aiTemperatureHint /
aiMaxTokens / aiSystemPrompt / aiSystemPromptPlaceholder / aiEnabledLabel / aiDisabledLabel

### ⚠️ 待办：Office365 SMTP AUTH 需手动开启

错误 `535 5.7.3 Authentication unsuccessful` 原因：  
Microsoft 2022 年起默认禁用 SMTP Basic Auth，需管理员为邮箱单独开启。

**操作步骤：**
1. 登录 https://admin.microsoft.com
2. 用户 → kennytseng@easycraft.ai → 邮件 → 管理电子邮件应用
3. 勾选 **已验证的 SMTP**（Authenticated SMTP）→ 保存
4. 等待 ~15 分钟生效后重新测试

或 PowerShell（需 Exchange Online 权限）：
```powershell
Set-CASMailbox -Identity "kennytseng@easycraft.ai" -SmtpClientAuthenticationDisabled $false
```
