## 详细记录

### 2A — 后端 `backend/src/routes/exams.ts`

实现全部 11 个端点：

| 端点 | 描述 |
|------|------|
| `GET /exams` | 列表，schoolId 过滤 + candidateCount |
| `GET /exams/:id` | 详情（单独 count 查询避免 Prisma _count findUnique 类型问题）|
| `POST /exams` | 创建考试，examType 枚举校验 |
| `PUT /exams/:id` | 更新 venue/date/status/examType/year |
| `DELETE /exams/:id` | 先 deleteMany candidates 再 delete exam |
| `GET /exams/:id/candidates` | 列出考生，含 student 姓名/IC/班级，支持 subjectCode 过滤 |
| `POST /exams/:id/candidates` | 双模式：class（批量按年级/班级/科目）/ individual（单个），重复守卫 |
| `DELETE /exams/:id/candidates/:id` | 移除单个考生 |
| `POST /exams/:id/generate-seating` | 顺序分配 A001–A999，内置 1.5s demo 延迟 |
| `GET /exams/:id/seating-plan` | 按座位号排序返回 |
| `PATCH /exams/:id/candidates/:id` | 考勤标记（present/absent/registered）|

**TypeScript 踩坑：**
- Prisma `findUnique` + `include: { _count: ... }` 不携带 `_count` 到返回类型，改用独立 `count()` 查询
- 所有 `req.params['x']` 需要显式 `as string` 转型（项目惯例）
- `req.query` 使用 `as { field?: string }` 具名接口而非 `Record<string, string>`
