#### 🐛 Bugs Found & Fixed

**Bug 1: Teaching Workload returns "Course not found"**
- Root cause: `GET /:id` route registered at line 67 intercepted `GET /workload-timetable` at line 267
- Fix: Moved `/workload-timetable` handler to before `/:id` in `courses.ts`
- File: `backend/src/routes/courses.ts`

**Bug 2: HOD/Principal can't view Teacher Detail (403)**
- Root cause: `GET /teachers/:id` role check only allowed `admin | manager | teacher`
- Fix: Added `hod` and `principal` to the allowed roles array
- File: `backend/src/routes/teachers.ts`

**Bug 3: Mobile Parent Portal — Quick Access title shows raw i18n key**
- Root cause: Code used `t('common.quickAccess')` but key is under `auth.quickAccess`
- Fix: Changed to `t('auth.quickAccess')`
- File: `mobile/src/pages/parent/ParentHomePage.tsx`
