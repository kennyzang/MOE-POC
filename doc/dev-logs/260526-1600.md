### PWA-01：Mobile PWA 离线 + Web Push 通知

**技术实现：**
- `vite-plugin-pwa` + Workbox `GenerateSW` 策略，自动生成 `sw.js` + `workbox-*.js`
- 离线缓存策略：
  - `/api/v1/sms/timetable` — StaleWhileRevalidate（24h）
  - `/api/v1/grades` — StaleWhileRevalidate（1h）
  - `/api/v1/attendance` — NetworkFirst（5s timeout fallback）

- Web Push 架构：
  - VAPID 密钥对启动时自动生成并存入 `SystemConfig`（不进 git）
  - `web-push` npm 包 + VAPID email `admin@moe.edu.bn`
  - 新增 `PushSubscription` Prisma 模型（endpoint UNIQUE，自动去重）
  - `pushService.ts`：`getVapidPublicKey` / `saveSubscription` / `sendPushToUser` / `sendPushToParentsOfStudent`
  - 失效订阅自动清除（410/404 状态码检测）
- 新增 API 路由 `/api/v1/push`：
  - `GET /vapid-key` — 公钥（无需认证）
  - `POST /subscribe` — 保存订阅（认证）
  - `DELETE /unsubscribe` — 取消订阅（认证）
  - `POST /send-test` — 发送测试 Push（认证，演示用）
- 考勤 absent 记录时同步发 Web Push 给家长（在已有 in-app 通知基础上叠加）
- 前端：

  - `PushNotificationBanner`：展示于教师 & 家长首页，支持一键开启/关闭/测试
  - `OfflineBanner`：全局监听 `online/offline` 事件，断网时顶部提示条
  - i18n `push.*` 键值（en/zh/ms 三语，mobile）
