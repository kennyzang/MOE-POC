# 质量检查清单（每个功能完成后必须执行）

标记功能完成前，逐一完成以下步骤：

1. **演示验证**
   - 编写 "Demo Verification Steps" 并逐条走通
   - 确保所有交互路径可达

2. **角色隔离验证**
   - 至少切换 2 个不同角色账号登录
   - 验证数据隔离正确（看不到其他角色的数据）

3. **表单校验**
   - 验证所有表单的错误提示为内联显示
   - 边界值测试（空值、超长、特殊字符）

4. **国际化检查**
   - 检查所有用户可见文本走 i18n（grep 硬编码字符串）
   - 切换三种语言验证翻译完整

5. **构建验证**
   - 运行 `cd pc && npm run build`（不仅是 `tsc --noEmit`）
   - 运行 `cd mobile && npm run build`
   - 确保零 TypeScript 错误和打包错误

6. **状态机验证**（适用于工作流功能）
   - 验证所有状态转换路径
   - 确保每个状态转换的前置条件正确

7. **数据一致性**（适用于仪表盘）
   - 在其他模块增删数据
   - 回到仪表盘验证数字自动更新

## 新增/升级依赖时额外检查
- 升级后必须在本地跑 `npm run build` 验证无类型错误
- 确认 lock 文件正确更新后再提交
